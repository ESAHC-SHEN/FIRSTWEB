# 言一 · 个人网站

> 一个放日常的地方：娱乐、学习、看天气、看日期、写文章、放照片。

**地址：** https://esahc-shen.github.io/FIRSTWEB/

纯 HTML / CSS / 原生 JavaScript，无框架、无构建，GitHub Pages 托管。
全站色调会随二十四节气流转——今天是哪个节气，站就是哪个颜色。

## 这里有什么

| 板块 | 内容 |
| --- | --- |
| 首页 | 时钟 + 天气、每日一言、站务条、五个专栏入口 |
| 文章 | 按年份归档的长文，首字下沉排版 |
| 随笔 | 碎片想法 |
| 相片馆 | 拍到的光，灯箱浏览 |
| 日历 | 日 / 月 / 年视图，农历、节气、节日 |
| 天气 | 当前天气与逐小时预报，可切换城市 |
| 学习 | 番茄钟、待办清单、倒数日、知识库链接 |
| 娱乐 | 每日一言 / 毒鸡汤、白噪音、摸鱼小工具 |
| 关于 | 关于我、站点编年史、友邻 |
